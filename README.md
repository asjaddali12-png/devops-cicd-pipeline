# DevOps CI/CD Pipeline

## Overview
An automated CI pipeline for a Python Flask application using
GitHub Actions and Docker.

## Tech Stack
- Python and Flask
- Docker
- GitHub Actions
- Git and GitHub

## Features
- Automated dependency installation
- Python syntax validation
- Docker image build
- CI execution on pushes and pull requests

## Application Endpoints
- `/` - Application welcome message
- `/health` - Health-check response

## Pipeline
Code Push → GitHub Actions → Install Dependencies →
Python Validation → Docker Build
